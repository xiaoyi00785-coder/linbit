# linbit 管理后台 · UI/UX 设计说明（v0.2）

> 范围：linbit 交易所运营后台（Back Office）。依据：`linbit-platform-excluded/business-rules.md`、`linbit-platform/docs/api`、`linbit-backend/services`（gateway / account / asset / kyc / wallet / order / market-data / admin / risk，Rust 撮合引擎）。
> 原型：本目录 React + Vite，全部 Mock 数据（示例用户 `lb_Demo8K2` / UID `80000001` / `demo***@example.com` / 邀请码 `LB8DEMO`）。颜色只来自 `src/tokens.css` 的 `:root --lb-*` 变量（主色 #abe127，背景 #070808）。

## 1. 设计原则
1. **密度优先**：13px 正文、32px 行高的表格，一屏展示 12–15 行；数字使用等宽数字（tabular-nums），金额右对齐。
2. **列表 → 抽屉 → 弹窗**三层：列表筛选定位；右侧抽屉看详情（不丢失列表上下文）；高危操作用居中弹窗二次确认。
3. **所有写操作可追溯**：高危操作必须填原因 + 2FA 码 + 第二人确认，写入审计日志（前后值对比）。
4. **参数类配置走变更单**：提交 → 审批 → 生效（立即/定时）→ 可回滚，禁止"直接改库"。
5. **状态色语义固定**：主色/绿=通过/正常/盈利，红=驳回/冻结/亏损/高风险，琥珀=待处理/中风险，蓝=处理中，金=合伙人等级/奖励/置顶。
6. **职责分离（SoD）**：提交人 ≠ 审批人；初审 ≠ 复核。
7. **默认脱敏**：邮箱、手机、证件号默认打码，查看明文需权限并记审计。

## 4. 关键流程
### 4.1 KYC 审核
提交 → 自动检查（OCR 字段比对、人脸相似度 ≥80%、活体、证件有效期、证件重复、制裁/PEP、限制国家）→ 进入队列（按等级/国家自动分配，SLA 2h）→ 审核员在抽屉中并排看证件与 OCR 对比 → 通过 / 驳回（结构化原因 + 多语言用户文案）/ 转复审。L2 额外地址证明 + 人工复核。结果触发站内信/邮件，KYC 等级变更写审计。

### 4.2 提现审批（风控 + 双人）
1. 用户提交（USDT 单笔 12 ~ 20,000，平台手续费 0，只扣链上 Gas，实时估算：Arbitrum≈1 / BNB Chain≈1 / TRON≈2 / Ethereum≈10 USDT；到账 = 数量 − Gas）。
2. 风控引擎自动检查：账户状态、安全冷却（改密/解绑 2FA 24h、绑定邮箱手机 6h）、白名单/新地址、KYT 地址风险、限额、充提比/未交易直提、余额对账、设备/IP 关联账户 → 输出风险分 0–100。
3. 路由：风险分 ≤20 且 ≤1,000 USDT → 自动放行；否则初审；≥5,000 USDT 或风险分 >40 → 必须复核（第二人，系统禁止同一人）。
4. 审批弹窗需 Google 2FA 码 + 意见；驳回可选"仅退回 / 冻结提现 / 冻结账户"。
5. 放行后进入签名队列 → 广播 → 链上确认；进度条在抽屉顶部展示。热钱包低于阈值时在看板和列表顶部告警。

### 4.3 用户冻结
用户详情抽屉 → 冻结/限制 → 选范围（登录/交易/提现/划转/充值入账/跟单）、原因分类、期限、工单号、是否通知 → 风控主管确认后生效 → 用户状态标签变化，审计记录。解冻流程对称。

### 4.4 上币 / 交易对
币种：基础信息 → 网络与合约地址 → 钱包接入测试（小额充提）→ 上线审批 → 开放充值 → 开放交易。交易对：精度、最小下单额、分区，支持定时开盘（先挂单后撮合）、暂停交易、批量操作。仅现货撮合，**不提供杠杆现货/借币**。

### 4.5 合约参数
每个合约：最大杠杆（BTC/ETH 200x，其余 10–125x，美股较低）、Maker/Taker（加密/黄金 0.05%/0.05%，美股 0%/0.04%）、资金费周期与上下限、价格偏离保护、平台持仓上限、交易状态（交易中/仅减仓/暂停）、12 档阶梯维持保证金（MMR 0.25% → 50%）。全部经变更单，审计保存 JSON diff，支持回滚上一版本。

### 4.6 手续费（v0.2 按已确认规则重写）
全站统一费率，**不设 VIP 等级**：现货 Maker/Taker 0.1%（成交才收，从收到的币种扣）；合约 Maker/Taker 0.05%，按仓位价值，开仓、平仓各收一次；强平单按 0.05%。提现平台手续费 0，仅收链上 Gas。页面分 4 个 Tab：交易费率（可发起变更）/ 提现费用（各网络 Gas 估算，只读）/ 计费规则 / 变更记录（含回滚）。费率变更走变更单：超级管理员 + 财务复审双人审批，生效前 24h 前台公告。用户列表中 VIP 列改为「身份」（普通用户 / 合伙人等级 / 带单员）。

### 4.7 活动 / 奖励 / 积分
活动类型：新人任务（合计 215 USDT 体验金 + 抵扣券）、交易赛、邀请返佣、体验金、手续费优惠、签到积分。配置：人群、时间、预算、任务-奖励表、反作弊（同设备一份、持仓 <60s 不计、对敲不计、发放前风控复核）。奖励发放支持人工补发（>1,000 USDT 需财务复核）与回收。积分：获取规则 + 商品库存 + 兑换记录。

### 4.9 返佣配置
合伙人等级按直推用户近 30 日合约量：普通（审核通过）合约 30% / 现货 20%；白银 ≥5M 40%/25%；黄金 ≥20M 45%/30%；钻石 ≥50M 50%/35%。Override：上级拿下级合伙人佣金 10%，平台出资，最多 2 级。每日结算至资金账户，推荐关系终身绑定。普通邀请：被邀请人手续费 10%，1 年，单级。不叠加；跟单分润不计入返佣。修改走变更单 + 审计。

### 4.8 跟单 / 策略
带单员入驻审核（KYC L2、资金、交易笔数）→ 带单中 / 暂停 / 下架并结算。仅合约跟单。参数：分润 0–50%（默认 10%，每日结算，不计入返佣）、最多跟随 10 位、跟单杠杆 1–100x、最低 10 USDT、每日结算；回撤 >50% 自动暂停。网格策略（仅现货，2–100 格，等差/等比，TP/SL）可查看与强制停止。

### 4.9 内容 / 公告
分类：公告、上新、活动、帮助中心、Banner、弹窗。多语言 Tab 编辑、推送渠道（站内信/Push/邮件）、定时发布、置顶；发布需审核。

### 4.10 审计日志
记录所有写操作 + 敏感查看 + 导出 + 登录：时间、管理员、角色、模块、动作、对象、IP/UA、请求 ID、级别（普通/敏感/高危）、结果、前后值 diff。只追加、不可修改，保留 ≥5 年，每日向内审推送高危摘要。

## 5. 数据看板 KPI
- 交易：24h 总成交额、合约/现货拆分、成交额构成（加密/黄金/美股/现货）、热门合约 Top5、未平仓 OI、多空比。
- 收入：24h 手续费收入及趋势。
- 用户：新注册、新 KYC、转化率、DAU、用户增长图。
- 资金：24h 净流入（充/提）、平台总资产、热钱包占比、热钱包低余额告警、最新大额提现。
- 风险：24h 强平金额、风险准备金、高风险仓位数、风控拦截奖励数。
- 运营：跟单 AUM、带单员数、活动奖励支出与预算消耗。
- 待办：KYC 待审、提现待初审/待复核、充值待人工、带单申请、内容待审（一键直达）。
