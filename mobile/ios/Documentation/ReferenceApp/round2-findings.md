# EasiCoin 第二轮实机研究

设备：iPhone 16 Pro Max，iOS 26.6.1，USB。截图像素 1320×2868，对应逻辑点 440×956（@3x）。账户已登录，总资产 0 USDT。本轮没有下单、没有充值、没有确认跟单。

证据等级：

- 已验证：无障碍树或截图里直接看到。
- 截图测量：从已保存 PNG 取样或按点坐标换算，不是设计稿标注。
- 行为推断：操作后界面变化支持这个结论，但没有单独测动画时长。
- 未验证：这轮没做到。

上一轮已有截图 `01`–`06` 没有重拍。本轮新增 `07`–`20`。没有 markdown 进度文档可续，所以这份是第二轮记录，不覆盖那些 PNG。

## 1. 第一轮遗漏

第一轮只停在首页、合约首屏、事件合约、现货行情列表，没有进入币种详情，没有走完现货下单链路，没有打开委托类型，没有看跟单，也没有把资产页存成文件。滚动深度、键盘、确认弹窗都没做。

## 2. 本轮新打开的页面和入口

已验证的链路：

1. 行情 → 市场 → 现货列表 → 点 BTC/USDT 行 → 币种详情。
2. 详情里切到深度图、最新成交。
3. 详情底部「交易」进入现货交易页，底栏选中项变成「现货」。
4. 现货交易页：买入/卖出、限价/市价/计划委托。
5. 资产总览（无余额）。
6. 首页「跟单」→ 跟单广场 →「我的跟单」。

新看到的入口：

- 币种详情：周期（1分、15分、1小时、4小时、1天、更多）、指标（MA、BOLL、EMA、撑压线、超级趋势、VOL、MACD，屏外还有 KDJ、OBV、RSI、WR）、订单表、深度图、最新成交、第 4 个标签（无文字）、预警、交易。
- 现货交易顶栏：现货、策略、理财、闪兑。本轮只停在「现货」。
- 跟单广场：公域内容、私域、机构信号（带 New）、排序（收益率、胜率、收益额、交易频次、跟单人数，屏外还有综合带单资金规模）、30日、跟单广场、我的跟单、申请成为带单员。

## 3. 新看到的弹窗和交互

已验证：

- 首页活动弹窗可点关闭钮关掉。关闭后回到首页，不进入活动页。位置约在屏幕中部，圆角黑卡片，下面有关闭圆钮。尺寸未逐边测量。
- 事件合约有分步引导。看到第 1 步「划转资产」和第 2 步「合约到期时间 / 在此设置合约到期时间」。第 3、4 步未看。点关闭后引导消失。
- 计划委托先出居中「温馨提示」：「由于行情波动等原因，计划委托触发后可能委托失败」。有「不再提示」和「确定」。点「确定」后才出现表单，没有提交订单。
- 数量框获焦后出现系统数字键盘（带小数点、删除），键盘上方右侧有绿色「完成」。无障碍树里没有「完成」这个元素，只能按像素点。
- 市价卖出时，价格框不可编辑，显示「市价」和 USDT；数量框单位是 BTC。
- 限价单有价格、数量、交易额。计划委托有触发价格、价格（USDT）、限价单、数量。
- 卖出可用资产显示 0 BTC；买入侧此前看到的是 USDT 计价。切换买卖会改按钮文案（买入 BTC / 卖出 BTC）和可用单位。
- 空委托是「委托(0)」，旁边是「交易机器人(0)」「只看当前」「全部撤销」。没有历史成交页。
- 数量获焦时出现「最小下单数量为 0.0001 BTC」。这是这一状态下看到的提示，不是提交失败文案。
- 跟单广场可以滚动（截图像素有变化，无障碍树没报变化）。「我的跟单」是空态：总收益和今日收益为「--」，正文「暂无数据」。

未验证：下单确认弹窗、提交成功/失败、当前委托详情、历史成交、Toast、Loading、日期选择器、长按、左滑、下拉刷新、K 线十字线和缩放、盘口点价回填。没有为了看这些状态去提交订单。

## 4. 组件（只记已看到的）

| 组件 | 已看到的行为 | 可复用场景 |
|---|---|---|
| 底栏 | 首页、行情、合约、现货、资产。进入交易页后「现货」成为选中项 | 全局 |
| 行情行 | 币对、成交额、最新价、人民币折合、涨跌幅色块。整行可点进详情 | 首页榜、行情列表 |
| 买卖切换 | 两个圆角块，选中买入为绿，选中卖出为红 | 现货 |
| 委托类型 | 底部或覆盖层，标题「委托类型」，选项限价单、市价、计划委托（带 New） | 现货 |
| 盘口 | 价格 + 数量两列，中间现价。精度旁有 0.01 和买卖比例条 | 现货、合约、详情 |
| 数量输入 | 获焦出数字键盘；市价时带币种单位；旁边有滑杆 | 现货 |
| 主按钮 | 「买入 BTC」「卖出 BTC」，颜色跟方向一致。本轮未点 | 现货、合约 |
| 空态 | 资产总览插画 + 充值；我的跟单「暂无数据」；合约无仓位文案 | 资产、跟单、合约 |
| 提示对话框 | 标题、说明、勾选、单按钮「确定」 | 计划委托 |

组件的内边距、字号、圆角多数还是截图估算，见下一节。没有拆成可直接照抄的 SwiftUI 尺寸表。

## 5. 视觉 Token（截图取样）

取样来自已保存 PNG，置信度中等：取的是按钮或色块内部的像素，不是设计标注。

| Token | 值 | 依据 |
|---|---|---|
| 页面背景 | #FFFFFF | `02-home.png` 顶部内容区 |
| 搜索底 | 约 #F0F0F0–#F3F3F4 | 首页搜索条区域取样 |
| 主按钮黑 | 约 #101111 | 首页「充值」区域最深像素 |
| 涨 / 买入 | #5FBB6E | 现货买入色块、行情涨幅色块 |
| 跌 / 卖出 | #DB5857 | 行情跌幅色块、市价卖出按钮 |
| 合约开仓绿 | 约 #58B868 | 合约页绿色按钮区域，和买入绿同一族 |

未取样，因此不写进 Token：分割线、次级文字、禁用灰、警告色、卡片阴影、导航栏精确高度。

截图测量（逻辑点，置信度中等）：

- 状态栏时间大约在 y=25pt。
- 现货顶部分段「现货」大约在 y=71pt、高约 18pt。
- 底栏标签大约在 y=913pt、字高约 12.5pt。底栏背景在首页截图底部仍是白色。
- 键盘「完成」大约在 (390, 609)pt。

这些是 OCR 框换算，不是 Auto Layout 常量。
