# 聊天室登录拦截（2026-11-08）

按用户最新确认：聊天室登录后才能查看与发言，替代早期游客可读规则。保留 Linbit 品牌与中文。

- 首页宫格、用户中心快捷入口均汇入行情聊天室；行情标签及直接 ChatRoomTab 调用统一显示游客登录空态。
- 游客不创建行情入口的 ChatViewModel，不请求房间/消息接口，不订阅聊天室 WS。直接调用 ViewModel 的读取/分页/发送方法也检查真实会话。
- 登录目标保存在 AppRoot 会话 key 外的 rememberSaveable 状态；登录成功返回聊天室，取消登录清除目标。成功回调读取最新会话，不误用登录前捕获的布尔值。

- 群组列表请求取消 No-Auth 标记，已登录请求可附带鉴权。此修改只约束 Android；不代表服务端匿名 GET 权限已经收紧。
